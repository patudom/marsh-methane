# Coupled CH₄ ↔ temperature feedback model

A dependency-free JavaScript model of the loop

```
temperature → natural CH₄ emissions → CH₄ burden → radiative forcing → temperature
```

driven by CMIP6 / ScenarioMIP SSP pathways, plus the Python reference it was
ported from and a validation harness that keeps the two in agreement.

A 250-year run takes **~1 ms**, so a dashboard recomputes on every slider drag
rather than interpolating a precomputed grid.

## Files

| File | What it is |
|---|---|
| `ch4feedback.js` | The model. ES module, no dependencies. This is what your dashboard imports. |
| `ssp-ch4-feedback.json` | Scenario inputs for all 8 SSPs, 1750–2300 (194 KB, ~55 KB gzipped). |
| `ch4feedback.py` | Python reference implementation — the authority the JS is checked against. |
| `build_bundle.py` | Regenerates the JSON bundle and the validation fixtures. |
| `validate.mjs` | `node validate.mjs` — replays 54 Python fixtures in JS plus 11 physical invariants. |
| `validation_fixtures.json` | Expected values from the Python, generated by `build_bundle.py`. |
| `example.mjs` | Runnable Node demo / CSV exporter. |
| `package.json` | Sets `"type": "module"`; `npm run validate` / `example` / `build`. |

## Running it

Node **or** the browser — it is a plain ES module with no dependencies.

| How | Works? | Notes |
|---|---|---|
| `import` from an ES module | yes | The normal path. `package.json` sets `"type": "module"`. |
| `node example.mjs` | yes | Included runnable demo — see below. |
| `node ch4feedback.js` | yes on Node ≥ 20.19 / ≥ 22.7 | Those versions auto-detect module syntax. Exits 0 with no output: the module has no `main`. Older Node throws `SyntaxError: Unexpected token 'export'` — rename to `.mjs` or add `"type": "module"`. |
| `require('./ch4feedback.js')` | yes on Node ≥ 22.12 | `require(esm)` is supported because there is no top-level await. |
| `<script type="module">` | yes | No bundler needed. |

**One gotcha: `fetch()` does not read local files in Node.** Node has a global
`fetch`, but the `file:` scheme is unimplemented, so the browser-style
`await (await fetch('./ssp-ch4-feedback.json')).json()` throws
`TypeError: not implemented... yet...`. In Node, read it from disk:

```js
import { readFileSync } from 'node:fs';
const bundle = JSON.parse(
  readFileSync(new URL('./ssp-ch4-feedback.json', import.meta.url), 'utf8'));
```

Tested on Node v22. Language features used are `Float64Array`, `??` and
optional chaining, so Node 14+ is fine; `performance.now()` in `validate.mjs`
needs Node 16+.

## Quick start (browser)

```js
import { run, runDecomposed, rebaseTemperature, listScenarios }
  from './ch4feedback.js';

const bundle = await (await fetch('./ssp-ch4-feedback.json')).json();

// one run
const out = run(bundle, 'ssp245', {
  gammaWetland: 20,     // feedback strength, Tg CH4 yr-1 K-1
  ecs: 3.0,             // equilibrium climate sensitivity, K
  startYear: 1850,
  endYear: 2100,
});
// out.year, out.ch4, out.temperature, out.forcing, out.tau, out.eNatural,
// out.sink, out.ch4Cmip6  — all Float64Array, same length

// temperature as an anomaly vs 1850–1900, the way IPCC figures report it
const { temperature } = rebaseTemperature(out, 1850, 1900);

// the headline pair for a feedback dashboard: run twice and difference
const d = runDecomposed(bundle, 'ssp245', { gammaWetland: 20 });
d.finalDeltaCh4;          // +301 ppb of CH4 that the loop itself caused
d.finalDeltaTemperature;  // +0.091 K of warming that the loop itself caused
d.amplification;          // T_with / T_without
```

## API

**`run(bundle, slug, params)`** → arrays keyed `year, ch4, tau, forcing,
temperature, temperatureDeep, eNatural, sink, ch4Cmip6`, plus `params`,
`climate` (`{lambda, ecs, tcr}`) and `feedbackWm2PerK`.

**`runDecomposed(bundle, slug, params)`** → `{withFeedback, withoutFeedback,
deltaCh4, deltaTemperature, finalDeltaCh4, finalDeltaTemperature,
amplification}`. Runs the model twice, once with `gammaWetland` and
`gammaPermafrost` zeroed, and differences them.

**`rebaseTemperature(result, baseStart, baseEnd)`** → `{offset, temperature}`.
The model's own zero is the 1750 state; IPCC figures use 1850–1900.

**`listScenarios(bundle)`** → `[{slug, label, ch4_rmse_ppb,
ch4_2100_error_pct, warming_2081_2100_K, calibration_scenario}]`, ready for a
picker. Includes each scenario's skill so you can flag the weak ones.

**`toRows(result, {rebase})`** → array of plain objects, for charting libraries
that want rows.

**`feedbackWm2PerK(params)`** → the feedback strength in W m⁻² K⁻¹, so a UI can
show where a slider sits relative to AR6's assessed range.

**`erfCh4(ch4, n2o)`**, **`erfCh4Extras(ch4)`**, **`climateParams(params)`**,
**`paramsFromBundle(bundle)`**, **`CONST`**, **`DEFAULTS`** are also exported.

### Parameters

Pass any subset; the rest come from the bundle's calibrated defaults.

| Parameter | Default | Units | Notes |
|---|---|---|---|
| `gammaWetland` | 20 | Tg CH₄ yr⁻¹ K⁻¹ | **The positive leg.** Slider range 0–40. |
| `gammaPermafrost` | 0 | Tg CH₄ yr⁻¹ K⁻¹ | Additive, if you want it separate. |
| `sTemperature` | −0.0408 | K⁻¹ | **The negative leg** — dln(τ)/dT. |
| `ecs` | 3.0 | K | AR6 best estimate. Range 2–5 is defensible. |
| `tauBase` | 10.878 | yr | Calibrated. See *Calibration* below. |
| `eNat` | 155.7 | Tg CH₄ yr⁻¹ | Calibrated natural source at T = 0. |
| `forcing2co2` | 3.93 | W m⁻² | AR6 Ch.7. |
| `cSurface`, `cDeep` | 7.3, 106 | W yr m⁻² K⁻¹ | Two-layer heat capacities. |
| `kappa`, `epsilon` | 0.677, 1.29 | — | Heat exchange and its efficacy. |
| `ozoneTempFeedback` | −0.037 | W m⁻² K⁻¹ | Ozone forcing's own T response. |
| `forcingScale` | 1.0 | — | Scales non-CH₄ forcing, for sensitivity tests. |
| `startYear`, `endYear` | full range | year | Any window inside 1750–2300. |
| `substeps` | 4 | per year | RK4 steps. Must match Python to validate. |
| `c0` | `null` | ppb | Initial CH₄. `null` = prescribed CMIP6 value; `'steady'` = the parameters' own steady state. |

## The physics

```
CH₄ burden   dB/dt = E_anth(t) + E_nat + γ·T − B/τ
CH₄ lifetime τ = τ_base · α_chem(t) · (1 + ΔCH₄·2.54e−4) · (1 + T·s_T)
Temperature  C  dT/dt  = F − λT − εκ(T − T_d)
             C_d dT_d/dt = κ(T − T_d)
Forcing      F = f_other(t) + F_CH₄(CH₄,N₂O) + CH₄'s ozone and strat-H₂O terms
                 + CH₄'s aerosol term + ozone's temperature feedback
```

### The loop is damped, not runaway — and the dashboard should say so

Two effects oppose the wetland feedback, and both are in the model:

- **Lifetime shortens with warming** (`sTemperature = −0.0408 K⁻¹`): a warmer
  atmosphere holds more water vapour, which makes more OH, which destroys CH₄
  faster. At the top of the AR6 feedback range this roughly *halves* the loop's
  effect — 2938 ppb in 2100 with the damping versus 4092 ppb without it, under
  SSP5-8.5.
- **Ozone's forcing falls with warming** (−0.037 W m⁻² K⁻¹).

Amplification at γ = 40 (above the top of AR6's range) is **1.05×**. "Does this
run away?" is the first question any viewer will ask, and the answer the model
gives is no.

### The feedback strength is the honest uncertainty

AR6 WGI Ch.5 assesses the combined non-CO₂ biogeochemical feedback at
**0.02–0.09 W m⁻² °C⁻¹, low confidence** — that is roughly **7–30 Tg CH₄ yr⁻¹
K⁻¹** here, and `feedbackWm2PerK()` converts a slider position back so you can
show it. Over that range, the loop's own contribution by 2100 is:

| Scenario | γ = 7 | γ = 20 | γ = 30 |
|---|---|---|---|
| SSP1-2.6 | +55 ppb, +0.02 K | +166 ppb, +0.07 K | +259 ppb, +0.10 K |
| SSP2-4.5 | +100 ppb, +0.03 K | +301 ppb, +0.09 K | +470 ppb, +0.14 K |
| SSP3-7.0 | +175 ppb, +0.04 K | +522 ppb, +0.11 K | +808 ppb, +0.17 K |
| SSP5-8.5 | +176 ppb, +0.04 K | +527 ppb, +0.13 K | +821 ppb, +0.20 K |

A factor of four in the parameter gives a factor of four in the answer. Showing
a single number here would misrepresent the science; a slider is the honest UI.

## Where the numbers come from

- **Emissions and prescribed concentrations** — the Hector scenario input tables
  (JGCRI), which repackage RCMIP v5.1.0 harmonised SSP emissions (Nicholls et
  al. 2020) and the CMIP6 prescribed GHG concentrations of Meinshausen et al.
  (2020).
- **Forcing and chemistry coefficients** — FaIR 2.1's default species
  configuration (AR6-consistent): radiative efficiencies, tropospheric
  adjustments, ozone and aerosol coefficients, and the CH₄ lifetime
  sensitivities to CH₄, N₂O, EESC, NOₓ, VOC and temperature.
- **GHG forcing formulas** — Meinshausen et al. (2020), including the CO₂–N₂O
  and CH₄–N₂O band overlaps.
- **Energy balance** — two-layer, Geoffroy et al. (2013) / Held et al. (2010)
  structure, tuned to AR6's ECS 3.0 K and TCR 1.8 K.

### Precomputed vs live

`f_other` is the pre-summed forcing from everything the live model doesn't
touch: CO₂, N₂O, 26 halocarbons, ozone from N₂O/EESC/NOₓ/VOC/CO,
aerosol–radiation, aerosol–cloud, black carbon on snow, and land-use albedo.
`alpha_chem_ext` is the CH₄-lifetime scaling from N₂O, EESC, NOₓ and VOC.
Splitting this way means the browser integrates only the coupled part.

## Validation

`node validate.mjs` — **335/335 checks pass.**

- 54 parameter combinations replayed from the Python; worst relative difference
  **7.4 × 10⁻⁸**. Both implementations use fixed-step RK4 with matched substeps,
  so this is float64 round-off ordering, not a modelling difference. The
  fixtures are generated from the *rounded* arrays that actually ship, so the
  test measures the model rather than my JSON precision.
- Mass balance closes in integral (Simpson) rather than differential form —
  a central difference on annual output would mostly measure its own truncation.
- Monotone in feedback strength; the loop is damped; the lifetime feedback
  opposes the wetland feedback; substep-count insensitive.
- AR6 anchors: ECS 3.00 K, TCR 1.80 K, 2011–2020 warming 1.02 K (observed 1.09).

## Calibration

`tauBase` and `eNat` are fitted jointly across SSP1-2.6, SSP2-4.5, SSP3-7.0 and
SSP5-8.5 to reproduce the prescribed CMIP6 CH₄ pathways over 1850–2100, RMSE
**48 ppb**. The fit is done with the wetland feedback **off**, because the CMIP6
concentration pathways come from MAGICC7, which holds natural CH₄ emissions
constant — so turning `gammaWetland` on afterwards is genuinely an *added*
feedback, not a re-tuning of the baseline.

**These are effective parameters, not measurements.** The fit gives
τ_base = 10.88 yr (≈10.4 yr present-day) and E_nat = 156 Tg yr⁻¹. Fixing E_nat
to the bottom-up ~205 Tg yr⁻¹ (Saunois et al. 2020) yields a more realistic
9.1 yr present-day lifetime but more than doubles the CH₄ error. History
constrains the product of the two, not each separately. `bundle.calibration`
carries the fitted values, the window and the per-scenario skill.

## Known limitations

- **SSP4-3.4 and SSP4-6.0 track the prescribed CH₄ pathway poorly** (+21% and
  +17% at 2100). Prefer the four calibration scenarios; `listScenarios()`
  exposes the skill scores so a UI can warn or exclude.
- **CO₂ and N₂O are prescribed, not modelled.** Only the methane cycle
  responds to temperature. Warming also releases CO₂ from land and ocean — a
  larger feedback than the methane one — and this model does not include it, so
  it is not a complete "carbon-cycle feedback" tool.
- **No permafrost dynamics.** `gammaPermafrost` is a linear add-on to the
  wetland term. Real permafrost release is non-linear, partly irreversible and
  weakly constrained.
- **Contrails, solar and volcanic forcing are omitted**, which is most of the
  0.04 W m⁻² and ~0.07 K gaps against AR6.
- **`f_other` uses the prescribed CH₄ for the N₂O band overlap**, so N₂O forcing
  doesn't respond to live CH₄. The error is ~0.002 W m⁻² — deliberate, so
  `f_other` can stay precomputed.
- **Unit note:** this model uses 2.8438 Tg CH₄ per ppb (the exact
  mole-fraction-to-mass conversion), because FaIR's calibrated sensitivities
  assume it. IPCC assessment tables use 2.75, which additionally corrects for
  surface networks over-sampling the CH₄-rich lower troposphere. The choice
  shifts the fitted `tauBase` and `eNat` by ~3% and nothing else.
